경로 입력 후 Enter를 누르거나 입력창을 벗어나면 자동 탐색합니다. 폴더 선택도 즉시 적용됩니다. Git 저장소 또는 저장소를 포함한 상위 폴더를 선택하세요. 탐색 깊이 3 · 경로 변경 시 기존 선택·제안·미리보기 초기화.

저장소

0개

에이전트별 표시는 규칙 파일의 설치 여부이며, 스킬 검증 결과는 상태 확인에 반영됩니다. ‘사용자 규칙’은 이 도구로 설치하지 않은 규칙 파일입니다. ‘검사 전’은 설치 흔적만 발견한 상태입니다. 저장소를 선택하면 검사와 미리보기가 자동으로 실행됩니다.

작업 경로를 확정하거나 폴더를 선택해 시작하세요.

배포 설정

0개 선택

설정은 선택한 저장소에 공통 적용됩니다. 기존 스킬은 동기화 시 유지됩니다. Gemini에는 공유 스킬이 없습니다.

로컬 전용은 생성 파일을 .gitignore에 추가합니다. 이미 Git이 추적하는 파일은 자동으로 추적 해제되지 않습니다. Git 공유도 커밋·푸시는 별도로 해야 합니다.

변경 미리보기

저장소를 선택하면 변경 미리보기가 표시됩니다.

저장소 선택 및 배포 설정 → 자동 검사·미리보기 → 변경 내용 검토 → 적용.
선택이나 설정을 바꾸면 미리보기를 다시 준비합니다. 적용 버튼을 누르기 전에는 파일을 변경하지 않으며, 적용 후에는 자동으로 재검사합니다.

저장소를 선택하세요.
